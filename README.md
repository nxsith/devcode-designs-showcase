# devCODE Designs

### A digital studio presented through an interactive web experience

A studio website designed to showcase digital services and creative work through clear content, expressive motion, and a coherent frontend system.

[Visit website](https://devcodedesigns.com) · [View my portfolio](https://nisith.dev/#projects)

## The challenge

An agency website needs to communicate capability and personality while helping potential clients understand the offer and take the next step. The work balances visual impact with readable information and responsive navigation.

## Experience highlights

- A visual presentation of the studio’s services and selected work.
- Reusable sections for team information, process, client feedback, and contact.
- Spatial transitions and interactive storytelling.
- Responsive layouts and coordinated typography, spacing, and motion.
- Clear calls to action that support project enquiries.

## My contribution

**Frontend development: interface architecture, motion direction, and frontend delivery.**

The focus was to turn the studio’s identity into an engaging website with a consistent visual and interaction language.

## Technology

**Next.js · React · TypeScript · Tailwind CSS · Framer Motion · GSAP**

The project has evolved through multiple frontend iterations. This showcase presents the agency website as one portfolio project rather than exposing the implementation repositories.

## Design priorities

| Priority | Application |
| --- | --- |
| Identity | A distinctive studio presence |
| Clarity | Services and work presented in readable sections |
| Interaction | Motion that supports the content journey |
| Responsiveness | Layouts adapted to different screen sizes |
